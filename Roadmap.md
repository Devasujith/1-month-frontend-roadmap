# 1 Month MERN Stack Frontend Learning Roadmap

A structured one-month learning plan to build a strong frontend foundation using the MERN stack - HTML, CSS, JavaScript, React, Git, GitHub and Deployment.

---

## 📌 Summary Overview

| Week | Module | Duration | Weekly Project |
| :--- | :--- | :--- | :--- |
| **Week 1** | HTML & CSS Foundation | Day 1 – Day 7 | Responsive Portfolio Website / Landing Page |
| **Week 2** | JavaScript Fundamentals | Day 8 – Day 14 | To-Do Application and Weather Application |
| **Week 3** | React Development | Day 15 – Day 21 | Notes Application / Movie Search Application |
| **Week 4** | Final Project Development & Deployment | Day 22 – Day 28 | Physiotherapy Clinic Website (Frontend) |

## 🟦 Week 1: HTML & CSS Foundation

* **Module Name:** HTML & CSS Foundation
* **Duration:** 7 Days (Day 1 - Day 7)
* **Learning Objectives:**
  * Understand the structure and syntax of HTML documents.
  * Apply semantic HTML elements to build meaningful page structures.
  * Create forms, tables, and lists for structured content.
  * Apply core CSS concepts to style and lay out web pages.
  * Build responsive, mobile-friendly layouts using Flexbox and Grid.

### Topics Covered
* **HTML:** HTML Structure, Semantic HTML, Forms, Tables, Lists.
* **CSS:** CSS Basics & Selectors, Box Model, Typography, Colors, Display & Position, Flexbox & CSS Grid, Responsive Design & Media Queries.

### Daily Learning Plan (Week 1)
* **Day 1:** *HTML Structure & Semantic HTML* — Study HTML document structure, tags, attributes, and semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **Day 2:** *Forms, Tables & Lists* — Practice building forms with different input types, data tables, and ordered/unordered lists.
* **Day 3:** *CSS Basics, Selectors & Typography* — Learn CSS syntax, selector types, specificity, font properties, and color systems (HEX, RGB, HSL).
* **Day 4:** *Box Model, Display & Position* — Study margin, border, padding, content areas, display types, and positioning schemes.
* **Day 5:** *Flexbox* — Practice one-dimensional layouts using Flexbox properties for alignment and distribution of items.
* **Day 6:** *CSS Grid, Responsive Design & Media Queries* — Build two-dimensional grid layouts and apply media queries for mobile, tablet, and desktop breakpoints.
* **Day 7:** *Weekly Project & GitHub Upload* — Build the weekly project end-to-end, review responsiveness across devices, and upload the repository to GitHub.

### Weekly Project
**Responsive Portfolio Website or Landing Page:** A multi-section page (home, about, skills, projects, contact) built with semantic HTML and styled using Flexbox and Grid, fully responsive across mobile, tablet, and desktop screens.

## 🟪 Week 2: JavaScript Fundamentals

* **Module Name:** JavaScript Fundamentals
* **Duration:** 7 Days (Day 8 – Day 14)
* **Learning Objectives:**
  * Understand core JavaScript syntax, variables, and data types.
  * Write functions and work with arrays, objects, and loops.
  * Manipulate the DOM and handle browser events.
  * Apply modern ES6+ features in day-to-day coding.
  * Consume REST APIs using Fetch, Promises, and Async/Await.

### Topics Covered
* **Core Concepts:** Variables & Data Types, Operators & Scope, Functions, Arrays & Objects, Loops.
* **Advanced Concepts:** DOM Manipulation & Events, ES6 Features, Fetch API & Promises, Async/Await, Local Storage.

### Daily Learning Plan (Week 2)
* **Day 8:** *Variables, Data Types, Operators & Scope* — Study `var`/`let`/`const`, primitive and reference types, operators, and function/block scope.
* **Day 9:** *Functions, Arrays & Objects* — Practice function declarations, expressions, arrow functions, array and object methods.
* **Day 10:** *Loops & Logic Building* — Solve practice problems using `for`, `while`, and `forEach` loops along with conditional logic.
* **Day 11:** *DOM Manipulation & Events* — Select and modify DOM elements dynamically and handle click, input, and form events.
* **Day 12:** *ES6 Features* — Practice destructuring, spread/rest operators, template literals, and modules.
* **Day 13:** *Fetch API, Promises & Async/Await* — Consume public APIs using Fetch, and handle asynchronous flows with Promises and `async`/`await`.
* **Day 14:** *Local Storage & Weekly Projects* — Persist application data using Local Storage and build/finalize the To-Do and Weather applications.

### Weekly Project
**To-Do Application & Weather Application:** A task manager with add, complete, and delete functionality backed by Local Storage, and a weather lookup application that fetches live data from a public weather API.

## 🟩 Week 3: React Development

* **Module Name:** React Development
* **Duration:** 7 Days (Day 15 – Day 21)
* **Learning Objectives:**
  * Understand React fundamentals, JSX syntax, and component-based architecture.
  * Manage component state and handle user interaction through events.
  * Use React Hooks (`useState`, `useEffect`) to manage state and side effects.
  * Build multi-page applications using React Router.
  * Integrate external APIs into React applications.

### Topics Covered
* **Core React:** React Introduction & JSX, Components & Props, State & Event Handling, `useState` & `useEffect`.
* **Applied React:** Forms & Conditional Rendering, Rendering Lists, React Router, API Integration.

### Daily Learning Plan (Week 3)
* **Day 15:** *React Introduction, Project Setup & JSX* — Set up a React project, understand the component tree, and practice writing JSX.
* **Day 16:** *Components & Props* — Build reusable functional components and pass data between them using props.
* **Day 17:** *State & Event Handling (`useState`)* — Manage local component state and respond to user actions such as clicks and input changes.
* **Day 18:** *`useEffect` & Side Effects* — Study the component lifecycle and use `useEffect` for data fetching and side effects.
* **Day 19:** *Forms, Conditional Rendering & Lists* — Build controlled forms, conditionally render UI, and render dynamic lists with keys.
* **Day 20:** *React Router* — Implement multi-page navigation using nested routes and route parameters.
* **Day 21:** *API Integration & Weekly Project* — Integrate a public API into the application and complete the weekly project.

### Weekly Project
**Notes Application or Movie Search Application:** A React application with component-based structure, local state management, and live data fetched from a public API, with basic client-side routing where applicable.

---

## 🟥 Week 4: Final Project Development & Deployment

* **Module Name:** Final Project Development & Deployment
* **Duration:** 7 Days (Day 22 – Day 28)
* **Learning Objectives:**
  * Plan and structure a production-style frontend project.
  * Develop a complete multi-page website using React.
  * Integrate forms and API calls into the application.
  * Test and debug the application prior to release.
  * Deploy the completed project and present it professionally.

### Topics Covered
* **Planning & Build:** Project Planning, Folder Structure, UI Development, Forms.
* **Delivery:** API Integration, Testing & Bug Fixing, Git & GitHub, Deployment (Netlify/Vercel).

### Daily Learning Plan (Week 4)
* **Day 22:** *Project Planning & Folder Structure* — Define page requirements, plan component hierarchy, and set up a clean, scalable folder structure.
* **Day 23:** *UI Development (Home & About)* — Develop the Home and About pages with consistent styling and layout.
* **Day 24:** *UI Development (Services)* — Develop the Services page, listing clinic services with structured content blocks.
* **Day 25:** *Contact Page & Appointment Form* — Build the Contact page and Appointment Form with input validation and user feedback.
* **Day 26:** *API Integration & Functional Testing* — Wire up form submission/API integration where applicable and test all interactive features.
* **Day 27:** *Bug Fixing & Version Control* — Fix identified issues, refactor code where needed, and manage changes using Git and GitHub.
* **Day 28:** *Deployment & Presentation* — Deploy the application using Netlify/Vercel, perform final checks, and prepare a professional walkthrough for review.

### Weekly Project
**Final Project — Physiotherapy Clinic Website (Frontend):** Comprising Home, About, Services, Contact, and Appointment Form pages, built as a cohesive, production-style, responsive React application.
